# Escobal, Ruben III M. — Developer & Entrepreneur Portfolio

A minimalist, high-performance portfolio website inspired by [sincerelyyyash.com](https://www.sincerelyyyash.com/), built for **Escobal, Ruben III M.** — Bachelor of Science in Computer Engineering student, business owner, and community secretary.

---

## 🌟 Highlights & Features

- **Formal Portrait**: Features your genuine studio portrait ([`ruben-formal.jpg`](file:///c:/Users/andre/Desktop/client/assets/ruben-formal.jpg)) in a clean, rounded avatar card beside the hero introduction with a live status badge (`4th Year BSCOE · ICCT`).
- **Aesthetic**: Direct design parity with [sincerelyyyash.com](https://www.sincerelyyyash.com/) — clean typography, centered `max-w-3xl` reading column, and subtle glassmorphic sticky top navigation.
- **Typography**: Editorial typography using **Bodoni Moda** with high-contrast serif stems, ball terminals, and italic slate-blue accents (`#9bb4cf`) across headlines, navigation links, and section titles, paired with clean modern sans-serif body copy (**Plus Jakarta Sans**) and **JetBrains Mono** for code and labels.
- **Dark / Light Theme Toggle**: Persistent theme switcher with instant CSS variables transition.
- **Inline Tech Chips**: Signature dash-bordered inline badges featuring official vector logos for Python, Java, HTML, JavaScript, and Budget Proposals.
- **Interactive Focus Blur on Hover & Select**: Hovering or clicking any card across **Projects**, **Work Experience**, **Skills**, and **Educational Attainment** spotlights and elevates it, smoothly blurring and dimming the sibling cards for a cohesive, modern focus effect.
- **Featured Projects**:
  1. *Food Cart POS & Daily Inventory*: Sales and stock management system.
  2. *AutoDeal · Dealership & Sales Tracker*: Vehicle listings, financing calculator, and contracts.
  3. *Barangay Document & Budget Portal*: Municipal document and budget proposal workflow.
  4. *Sensor Telemetry & Embedded Controller*: BSCOE hardware/telemetry prototype.
- **Experience Timeline**: Expandable cards for Barangay Mambugan secretary responsibilities, food cart and small car dealership ventures, and project organizing.
- **Academic Attainment**:
  - *ICCT Colleges*: 4th Year BS Computer Engineering (BSCOE)
- **Contact & Social**: Direct **Gmail Compose** button pre-configured with recipient and subject line in a new tab, one-click email address copy with toast notification, GitHub profile link (`rubeniii`).
